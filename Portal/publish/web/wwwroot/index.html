        SLO Definitions

        Per-(domain, stage) latency targets and per-domain exception-rate targets used by the SLO Burn-Rate Monkey (Google SRE multiwindow multi-burn-rate method) instead of a single flat threshold. Leave Stage blank for the domain-level exception_rate signal.

        • Signal — Latency measures one journey stage's duration against a threshold; Exception rate measures a domain's exception occurrences against its recent traffic (no Stage).
        • Target threshold (ms) — only for Latency: a single sample "passes" when it's at or below this value. Not used for Exception rate (that signal's pass/fail line comes from the raw occurrence count instead).
        • Target % — the SLO objective itself, e.g. 99 means "99% of samples must pass over the Window". The remaining 1% is the error budget the Burn-Rate Monkey watches.
        • Window (days) — how many days of history the error budget is calculated over. Fixed to 28-31 days: the alert thresholds (14.4x/6x/1x) are calibrated for a ~30-day error-budget period and do not scale with this value.
        • Enabled — disabled definitions are ignored by the Golden Signal Collector and the Burn-Rate Monkey (no samples collected, no alert possible) without deleting the row.
        • Alerting — a finding only fires when BOTH a short window and its matching long window burn through the error budget fast enough (page: ~5 min / ~30 min detection; ticket: slower, dashboard-only, no Teams/Email notification).

        KQL Queries

        The queries every agent and dashboard runs. A saved query overrides the one built into this release; reverting drops the override and goes back to the shipped text. Each save is a new version and the full text of every version is kept, so any of them can be restored.

        Queries reference telemetry by alias, never by subscription. Write app('{{SOURCE:cruise-core}}') and register the resource under Telemetry Sources. A literal /subscriptions/... path is rejected on save — that is what keeps the source catalog an allow-list of everything a stored query can read.

        Telemetry Sources

        Where telemetry is read from, by alias and environment. This is what makes pointing the platform at another subscription a row change instead of a redeploy — and it is the allow-list: a stored query can only reach a resource registered here.

        To move an agent to a different subscription, edit the row here — not the query. Queries name a source by alias, so changing cruise-core once repoints every query that uses it. The Used by column shows exactly which ones that is.

        Agent Budgets

        What each agent is allowed to spend. Measured over 32 real investigations, the Inspector's debate is 64% of every token this platform burns, and the rounds after the independent round 0 are 43% on their own.
