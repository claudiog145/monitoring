AppInsights Access Tokens

Manage Azure AppInsights tokens for multi-tenant access

How to Generate a Token

  1. Open Terminal or PowerShell
  2. Login to your Azure account: 
    az login --tenant YOUR-TENANT-ID
  3. Get access token: 
    az account get-access-token --scope https://management.azure.com/
  4. Copy the entire accessToken value (the long JWT string)
  5. Paste it in the form below
