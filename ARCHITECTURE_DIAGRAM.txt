## 2. Company Resolution Flow

```
CompanyAdapterProvider.GetAsync(profileKey = null)
│
├─ IF profileKey != null
│  └─► Return adapter for that company (no DB read)
│
├─ ELSE (profileKey is null)
│  │
│  ├─ Read ActiveCompanyProfile from DB (cache 30s)
│  │  │
│  │  ├─ IF ActiveCompanyProfile.ProfileKey != null
│  │  │  └─► Use that company
│  │  │
│  │  ├─ ELSE IF Company:DefaultProfileKey != null
│  │  │  └─► Use configured default
│  │  │
│  │  └─ ELSE
│  │     └─► THROW CompanyProfileResolutionException
│  │
│  └─ Load CompanyProfile from DB
│     │
│     ├─ IF profile is null or not enabled
│     │  └─► THROW CompanyProfileResolutionException
│     │
│     └─ Build ProfileDrivenAdapter
│        └─ Cache 30s
```

## 4. Cache & Invalidation

```
CompanyAdapterProvider
│
├─ _activeKey: volatile ActiveKeySnapshot
│  ├─ ProfileKey: string?
│  └─ ExpiresAt: DateTimeOffset (now + 30s)
│
├─ _snapshots: ConcurrentDictionary<string, Snapshot>
│  ├─ "arrivia" → Snapshot(adapter, expiresAt)
│  ├─ "demo" → Snapshot(adapter, expiresAt)
│  └─ "test" → Snapshot(adapter, expiresAt)
│
└─ Invalidate()
   ├─ _snapshots.Clear() ← All adapters cleared
   └─ _activeKey = null ← Active company re-read next call
```

Flow:
```
Request 1: GetAsync()
  └─► ReadActiveKeyAsync()
      └─► DB read (cache miss)
      └─► Store in _activeKey
      
Request 2 (within 30s): GetAsync()
  └─► ReadActiveKeyAsync()
      └─► Return cached _activeKey (no DB read!)
      
PUT /api/settings/company-profiles-active "arrivia"
  └─► SetActiveAsync("arrivia")
  └─► Invalidate()
      └─► _activeKey = null
      └─► _snapshots.Clear()
      
Request 3: GetAsync()
  └─► ReadActiveKeyAsync()
      └─► DB read again (cache was cleared)
```

## 5. API Flow

```
┌─ GET /api/settings/company-profiles ────────────────────┐
│  ├─ Query: SELECT * FROM monitoring.CompanyProfile      │
│  └─ Response: { profiles: [ {...}, {...} ] }            │
└────────────────────────────────────────────────────────┘

┌─ GET /api/settings/company-profiles-active ───────────┐
│  ├─ Query: SELECT * FROM monitoring.ActiveCompanyProfile │
│  └─ Response: { profileKey: "arrivia", updatedAt: ..., │
│               updatedBy: "..." }                        │
└────────────────────────────────────────────────────────┘

┌─ PUT /api/settings/company-profiles-active ───────────┐
│  ├─ Auth: Require X-Settings-Write-Secret header      │
│  ├─ Body: { profileKey: "arrivia" }                   │
│  ├─ Validate: Must exist and be enabled               │
│  ├─ Query: UPDATE monitoring.ActiveCompanyProfile     │
│  ├─ Call: adapterProvider.Invalidate()                │
│  └─ Response: { profileKey: "arrivia", ... }          │
└────────────────────────────────────────────────────────┘

┌─ GET /api/scout/packages?profileKey=arrivia ────────┐
│  ├─ Query: SELECT * FROM monitoring.InvestigationPackage │
│  │          WHERE ProfileKey = 'arrivia'            │
│  └─ Response: { packages: [ {...}, {...} ] }        │
└────────────────────────────────────────────────────────┘

┌─ GET /api/scout/packages (no profileKey) ──────────┐
│  ├─ Query: SELECT * FROM monitoring.InvestigationPackage │
│  │          (no WHERE on ProfileKey)                │
│  └─ Response: { packages: [ all companies ] }       │
└────────────────────────────────────────────────────────┘
```
